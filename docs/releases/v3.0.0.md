# MovieMuse v3.0.0 — Windows Worker 桌面化大更新

MovieMuse v3.0.0 将 Windows 算力端升级为独立桌面应用，并重新划分控制端与算力端的配置边界。MovieMuse 控制端继续负责任务调度和业务配置；Windows Worker 负责本机 GPU 环境、Whisper 模型文件和任务执行。

## 主要更新

- 提供独立的 `MovieMuseWorker.exe` 桌面窗口，不再通过 BAT 打开命令行和外部浏览器。
- 新增 MovieMuse 风格的 Worker 概览、活动和模型界面，并适配 4K 屏幕与 150% 缩放。
- 自动检测 NVIDIA GPU、显存、驱动和 CUDA 运行环境，并推荐合适的 Whisper 模型。
- 支持在 Worker 内安装或修复 CUDA 12、cuBLAS 和 cuDNN 9 运行环境。
- 支持 Whisper 模型下载、暂停、继续、取消、校验、更新和修复。
- 支持软件版本和模型版本检测。
- 新增 Worker 自动体检，区分“地址可访问”“待配对”和“可以接收任务”。
- MovieMuse 支持局域网自动扫描，也支持手动填写 Worker 地址并使用六位配对码安全连接。
- API Token 在配对时自动生成和保存，不再要求用户手工复制。
- Worker 本机数据迁移到 `%LOCALAPPDATA%\MovieMuse Worker`，升级应用不会丢失模型、GPU 运行环境、设置和日志。
- 修复任务中心分页统计、远程任务派发、FFmpeg 进度误报、模型仓库地址和 WebView 数据迁移等问题。

## 配置边界

MovieMuse 控制端管理：

- 是否启用 Windows Worker
- 当前使用的已安装 Whisper 模型
- 任务并发策略、翻译、转码、路径映射和回调地址

Windows Worker 管理：

- GPU、驱动和本机运行环境
- Whisper 模型实际存储和完整性
- 本机安全并发上限
- Worker 软件更新和诊断信息

设备、计算精度和 Windows 模型目录不再由控制端重复设置，避免两端配置互相覆盖。

## 安装

1. 下载 `Moviemuse-Windows-Worker-v3.0.0-win64.zip` 并完整解压。
2. 双击 `MovieMuseWorker.exe`。
3. 如果环境页提示缺少 GPU 运行环境，点击安装并在完成后重启 Worker。
4. 在模型页下载或验证推荐的 Whisper 模型。
5. 在 MovieMuse 控制端自动扫描 Worker，或手动填写 `http://WINDOWS-IP:18181`。
6. 输入 Worker 概览页显示的六位配对码完成连接。

发布包不包含 Whisper 模型，也不包含约 1.2 GB 的 NVIDIA 运行库。这样可以显著减小下载体积，并避免升级时重复下载本机数据。

## 从旧版升级

- 关闭旧 Worker 后，将 v3.0.0 解压到新的独立目录并启动。
- 首次启动会尝试迁移旧发布目录中的 `data\local-backend` 数据。
- 已经迁移到 `%LOCALAPPDATA%\MovieMuse Worker` 的数据会被直接复用。
- 如果控制端显示“待配对”，使用 Worker 当前显示的六位配对码重新连接。
- 不要把 Whisper 模型、GPU 运行库或旧 WebView 缓存复制进新程序目录。

## 系统要求

- Windows 10/11 64 位
- Microsoft Edge WebView2 Runtime
- 推荐 NVIDIA GPU；GPU 模式需要兼容的驱动
- Worker 默认监听 TCP 18181，控制端需要能够访问该端口

## 完整性校验

发布页面同时提供 `SHA256SUMS.txt`。下载后可以使用 PowerShell 校验：

```powershell
Get-FileHash .\Moviemuse-Windows-Worker-v3.0.0-win64.zip -Algorithm SHA256
```

校验结果应与 `SHA256SUMS.txt` 中的值一致。
