## UI redesign target

当前项目是本地 Media Toolbox 视频去重工具。

请参考 `docs/ui-reference/media-toolbox-dashboard.html` 的视觉和交互结构，重构现有前端页面。

设计方向：
- 专业媒体管理控制台
- 左侧扫描源与策略
- 中间重复组列表
- 右侧处理预览面板
- 顶部数据仪表盘
- 步骤流：选择媒体库 → 扫描重复 → 确认保留 → 批量移动

要求：
- 保留现有功能逻辑和接口
- 不要破坏扫描、移动、字幕任务功能
- 优先改 UI 结构、组件层级和样式
- 文件操作类按钮必须有确认弹窗
- 重复组需要展示“推荐保留原因”
- 支持浅色专业控制台风格
